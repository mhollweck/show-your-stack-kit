## How to log (for my agent)
Once per session, right after the first task is done, append ONE entry below.
Add a line to it later in the session only if something notable happens (a
correction, a delegation, a review, a failure). Eleven lines max. Patterns and
paraphrases, never code or secrets. Log without commentary: do not announce
entries, do not ask about the journal.

Entry format:
## YYYY-MM-DD (Day) · project: <allowlisted name or "private">
- task: what I wanted, in one line, and what shipped
- prompting: how many prompts; how the first one was shaped (one-liner, spec
  with acceptance criteria, pasted context, screenshot); plan mode yes or no
- workflow: the steps in order, e.g. plan > build > test > commit
- delegation: what went to subagents, background jobs, or scheduled runs vs
  what stayed in the main thread; models if pinned
- review: did I read the diff, ask for a review, or trust it; how deep
- verification: how I knew it worked (tests, build, manual check, nothing)
- vcs: branches, worktrees, commit size, anything unusual
- corrections: what I pushed back on, quoted short, and the rule it implies
- tools: plan mode, skills or commands, MCP servers, hooks, worktrees, model
  switches
- manual: what I did by hand outside the agent (testing in the app, design,
  deploy click, coordinating with people)
- notable: anything surprising, or a gem candidate

Check-ins: on the first session on or after day 7, ask me ONE question and log
the answer under "## Check-in · week 1": "What changed in how you work with
your agent this week?" On the first session on or after day 14 (or END, if
sooner): "What broke during this window, and what rule did it produce?" Log it
under "## Check-in · week 2". Never more than one question per week.

After END: stop logging. Remind me once to run Part 2 (EXTRACT.md from the kit
above), then set "reminded: yes" in this header so you do not repeat it.
Remove nothing.
